# C++ Slot Machine

A simple terminal-based slot machine written in C++.

## Features

- Randomized slot symbols
- Configurable machine dimensions
- Terminal spin animation
- Betting and credit system
- Winning-line detection

## Running

Compile and run:

```bash
g++ *.cpp -o slots
./slots
```

## About

Built as a small C++ project to practice classes, pointers, vectors, and basic game logic.
